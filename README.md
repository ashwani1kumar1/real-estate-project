# Real estate project

This repository contains a minimal Next.js app scaffold matching the project tree shown in the screenshot.

Files created:

- `pages/_app.js` — custom App importing global CSS
- `pages/index.js` — simple homepage
- `pages/api/hello.js` — example API route
- `styles/globals.css` — minimal global styles
- `next.config.js`, `.babelrc`, `.eslintrc.json`, `package.json`

To run locally:

1. npm install
2. npm run dev
